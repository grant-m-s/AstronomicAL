Built-in Plugin Reference
=========================

Bundled features are implemented as plugins and follow the same lifecycle as
third-party plugins.

Each page lists the plugin's main panels, mappings and outputs. The Plugin
Manager remains the source of truth for the exact contributions available in a
running installation.
